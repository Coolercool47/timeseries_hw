# Анализ временного ряда продаж

Домашняя работа: качество данных, описательный анализ, декомпозиция и проверка стационарности продаж одного товара.

Товар — **LUNCH BAG BLACK SKULL**, сумка для обеда с черепом, код `20727`. Он отличается от товара занятия `85123A`.

Источник: [UCI Online Retail](https://archive.ics.uci.edu/dataset/352/online-retail), Chen, D. (2015), [DOI 10.24432/C5BW33](https://doi.org/10.24432/C5BW33), CC BY 4.0. Период операций — 01.12.2010–09.12.2011.

## Запуск

Проверено с Python 3.14.3. Из корня репозитория:

```powershell
uv venv .venv
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
.\.venv\Scripts\python.exe -m notebook
```

Откройте `online_retail.ipynb`, выберите ядро `.venv` и выполните ячейки по порядку. Первый запуск требует интернета: исходный Excel скачивается в `data/raw/`; далее используется локальная копия. Данные и окружение исключены из Git.

Весь анализ и класс `SalesAnalysis` находятся в Notebook. Зависимости перечислены в `requirements.txt`.

## Методы и результаты

1. **Построение ряда.** Анализируется количество положительных продаж: `Quantity > 0`, `UnitPrice > 0`, документ без префикса отмены `C`. Возвраты не вычитаются. После отбора осталось **1 328 строк и 12 240 единиц**. Построены 374 дневных, 54 недельных и 13 месячных наблюдений; суммы совпадают, неполные границы отмечены.

2. **Качество.** В полях для агрегации пропусков нет. 224 пропуска `CustomerID` не мешают суммировать продажи. Из 82 дней без продаж товара 69 не содержат операций вообще, включая все 53 субботы; ещё в 13 дней продавались другие товары. Нули означают отсутствие зарегистрированных продаж при предположении полноты журнала и не заполнялись интерполяцией. 27 полных дубликатов сохранены как неоднозначные позиции документов.

3. **Выбросы.** Верхняя граница IQR — 103,38 шт. в день: 23 кандидата, на недельной частоте превышений нет. Максимум **04.08.2011 — 280 шт.**, включая одну позицию на 200 шт. Ошибка не установлена; пик согласуется с оптовой покупкой, поэтому значения не корректировались.

4. **Уровень и разброс.** По 372 полным дням среднее — **32,48**, медиана — **21,5**, стандартное отклонение — **38,58** единицы. Доля нулевых дней — 22,04%. Недельная агрегация уменьшает CV с 1,19 до 0,51. Скользящие среднее и разброс меняются во времени.

5. **Сезонность.** Профиль дней недели и ACF после удаления линейного тренда поддерживают недельный календарный рисунок. Выполнено робастное аддитивное STL-разложение с периодом 7 дней; крупные покупки остаются в остатке. Влияние режима работы магазина нельзя отделить от сезонности спроса. Годовая сезонность не установлена: период наблюдения слишком короток.

6. **Стационарность.** При уровне значимости 5% исходный ADF отвергает единичный корень (`p = 0,03235`), а KPSS отвергает стационарность уровня (`p < 0,01`). После разности с лагом 7 ADF даёт `p ≈ 4,37 × 10⁻¹⁰`, KPSS — `p > 0,10`: тесты согласуются со стационарностью уровня. Разброс остаётся неоднородным, поэтому **ковариационная стационарность не установлена**. ACF(7) = −0,527 указывает на возможное избыточное дифференцирование; разность рассматривается как проверенный вариант предобработки.

## Вывод

Данные пригодны для дальнейшего исследования дневных и недельных продаж с учётом календаря, крупных заказов и неоднозначных дубликатов. Все обязательные этапы анализа представлены в Notebook; модели прогнозирования в этой работе не строились.
